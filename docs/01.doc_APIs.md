# API Documentation

This document provides a comprehensive list of all API endpoints available in the Gascart E-commerce platform.

## Base URL
- **Production**: `https://api.gascart.app/api/v1`
- **Development**: `http://localhost:3000/api/v1`

## Authentication
Most routes require a Bearer Token in the `Authorization` header.
`Authorization: Bearer <token>`

---

## 1. General & Health
- **GET `/`**: Base API health check
- **GET `/health`**: Enhanced health status
- **GET `/api/v1/health`**: Simplified health check

## 2. Products
- **GET `/products`**: List all available products
- **GET `/products/:id`**: Get detailed information for a specific product
- **GET `/products/:productId/vendors/:vendorId`**: Get pricing and availability for a product from a specific vendor
- **POST `/products/upload`**: Upload product images (Admin only)
- **POST `/products`**: Create a new product (Admin only)
- **PUT `/products/:id`**: Update product details (Admin only)
- **PATCH `/products/:id/inventory`**: Update stock levels for a product (Admin only)
- **DELETE `/products/:id`**: Soft delete a product (Admin only)

## 3. Categories
- **GET `/categories`**: List all product categories
- **POST `/categories`**: Create a new category (Admin only)
- **PATCH `/categories/:id`**: Update category details (Admin only)
- **DELETE `/categories/:id`**: Soft delete a category (Admin only)
- **DELETE `/categories/:id/permanent`**: Permanently delete a category (Admin only)

## 4. Cart
- **GET `/cart`**: Retrieve the current user's shopping cart
- **POST `/cart/items`**: Add a product to the shopping cart
- **PATCH `/cart/items/:itemId`**: Update the quantity of an item in the cart
- **DELETE `/cart/items/:itemId`**: Remove a specific item from the cart
- **DELETE `/cart`**: Clear all items from the shopping cart

## 5. Orders
- **GET `/orders`**: Get a list of the current user's orders
- **GET `/orders/:id`**: Get details for a specific order
- **POST `/orders`**: Create a new order from the current cart
- **POST `/orders/:id/cancel`**: Cancel an existing order
- **GET `/orders/:id/invoice`**: Generate and download a PDF invoice
- **GET `/orders/admin/all`**: List all orders in the system (Admin only)
- **GET `/orders/admin/export`**: Export orders data to CSV (Admin only)
- **PATCH `/orders/admin/:id/status`**: Update the status of an order (Admin only)
- **PATCH `/orders/admin/:id/tracking`**: Update shipping tracking information (Admin only)

## 6. Users & Profile
- **GET `/users/me`**: Get the current user's profile information
- **PATCH `/users/me`**: Update the current user's profile details
- **GET `/users/addresses`**: List all saved addresses for the user
- **POST `/users/addresses`**: Add a new shipping/billing address
- **PATCH `/users/addresses/:id`**: Update an existing address
- **DELETE `/users/addresses/:id`**: Delete a saved address

## 7. Admin Management
- **GET `/admin/stats`**: Retrieve overview statistics for the admin dashboard
- **GET `/admin/audit-logs`**: Fetch system audit logs for tracking changes
- **POST `/admin/audit/log-auth`**: Record an authentication event in the audit log
- **GET `/admin/users`**: List all registered users
- **GET `/admin/users/:userId/orders`**: Get order history for a specific user
- **PATCH `/admin/users/:userId`**: Modify user accounts (permissions, status, etc.)
- **DELETE `/admin/users/:userId`**: Delete a user account
- **POST `/admin/users/create-admin`**: Provision a new administrative account
- **POST `/admin/users/export`**: Export user list to CSV
- **POST `/admin/orders/export-invoices`**: Batch export invoices as a ZIP file

## 8. Vendors
- **POST `/vendors/enquiry`**: Submit a new vendor registration enquiry
- **POST `/vendors/upload`**: Upload vendor-related documentation
- **GET `/vendors/product/:productId`**: List all vendors supplying a specific product
- **GET `/vendors`**: List all active vendors (Admin only)
- **POST `/vendors`**: Create a new vendor profile (Admin only)
- **PUT `/vendors/:id`**: Update vendor information (Admin only)
- **DELETE `/vendors/:id`**: Deactivate/Delete a vendor (Admin only)
- **GET `/vendors/enquiries`**: Review pending vendor enquiries (Admin only)
- **PATCH `/vendors/enquiries/:id`**: Approve or reject a vendor enquiry (Admin only)
- **POST `/vendors/assign`**: Assign a vendor to supply a product (Admin only)
- **PUT `/vendors/assign`**: Update product-vendor assignment terms (Admin only)
- **DELETE `/vendors/assign`**: Remove a vendor from a product listing (Admin only)

## 9. RFQs (Request for Quote)
- **POST `/rfqs`**: Submit a new Request for Quote
- **GET `/rfqs/my`**: List RFQs submitted by the current user
- **GET `/rfqs/all`**: List all RFQs in the system (Admin only)
- **GET `/rfqs/export`**: Export RFQ data to CSV (Admin only)
- **GET `/rfqs/export/pdf`**: Export RFQ data to PDF (Admin only)
- **PATCH `/rfqs/:id/status`**: Update the status of an RFQ (Admin only)

## 10. Consultants
- **GET `/consultants`**: List all available consultants
- **GET `/consultants/:id`**: Get details for a specific consultant
- **POST `/consultants/register`**: Register a new consultant profile
- **GET `/consultants/my-profile`**: Get the logged-in consultant's own profile
- **POST `/consultants/inquiries`**: Submit a new consultation request
- **GET `/consultants/inquiries`**: List consultation inquiries (User/Admin)
- **PATCH `/consultants/inquiries/:id/status`**: Update inquiry status (Admin only)
- **GET `/consultants/inquiries/export/pdf`**: Export inquiry list to PDF (Admin only)
- **PATCH `/consultants/:id`**: Update consultant profile (Admin only)
- **DELETE `/consultants/:id`**: Delete a consultant profile (Admin only)

## 11. Articles & Knowledge Hub
- **GET `/articles`**: List all published articles/blogs
- **GET `/articles/:slug`**: Get article content by its URL slug
- **POST `/articles`**: Create a new article (Admin only)
- **PATCH `/articles/:id`**: Update an existing article (Admin only)
- **DELETE `/articles/:id`**: Delete an article (Admin only)

## 12. Documents
- **GET `/documents`**: List public documents/resources
- **GET `/documents/:id`**: Get details for a specific document
- **POST `/documents`**: Upload/Create a new document entry (Admin only)
- **PUT `/documents/:id`**: Update document information (Admin only)
- **DELETE `/documents/:id`**: Delete a document entry (Admin only)

## 13. Payments & Webhooks
- **POST `/payments/create-order`**: Initialize a Razorpay payment order
- **POST `/payments/verify`**: Verify the signature of a completed payment
- **GET `/payments/status/:paymentId`**: Check the current status of a payment
- **POST `/webhooks/razorpay`**: Handle incoming payment status updates from Razorpay

## 14. File Uploads
- **GET `/upload/:bucket/files`**: List objects within a specific storage bucket
- **POST `/upload/:bucket`**: Upload a file to a specific storage bucket
- **POST `/upload/:bucket/rename`**: Rename an existing file in a bucket
- **DELETE `/upload/:bucket`**: Delete a file from a storage bucket

## 15. Careers
- **POST `/careers`**: Submit a new job application
- **GET `/admin/careers`**: List all job applications (Admin only)
- **PATCH `/admin/careers/:id/status`**: Update application status (Admin only)
- **POST `/admin/careers/signed-url`**: Generate temporary access URL for resumes (Admin only)
